# Просмотрщик табличных данных

Консольная программа на Python для просмотра текстового файла. Она читает записи из локального `.txt`-файла или по
ссылке и выводит выровненную таблицу.

## Установка зависимостей

Перед запуском программы и тестов необходимо установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Локальный файл:

```bash
python main.py -i data.txt
python main.py --input data.txt
```

Файл по ссылке:

```bash
python main.py -i https://gitlab.com/toptenov/automation_qa_intern_2026/-/raw/main/data.txt
python main.py --input https://gitlab.com/toptenov/automation_qa_intern_2026/-/raw/main/data.txt
```

Вывод части файла:

```bash
python main.py -i data.txt -s 3 -l 20
python main.py --input data.txt --start-line 10 --limit 50
```

## Условия

- На вход поступает <любое_название>.txt со списком атрибутов:
    - ФИО,
    - Возраст,
    - Адрес,
    - Дата
- Атрибуты разделены табуляцией
- Одна строчка - один человек
- При выполнении задания нельзя использовать готовые инструменты с помощью которых можно вывести на экран табличные
  данные
- Файл data.txt, подаваемый на вход, менять запрещается - CRC32 файла должен оставаться такой же = 0x2c083a45
- Если значение месяца превышает 12, следует считать, что день и месяц перепутаны, и поменять их местами 2026-15-03 →
  2026-03-15

## Особенности реализации

- В `data.txt` присутствует невозможная дата, поэтому программа не завершает работу с исключением, а выводит уведомление об ошибке и продолжает обработку остальных строк.
- Файл не загружается полностью в память. Обработка выполняется построчно.
- Можно указать, с какой строки начинать чтение (`--start-line`), и ограничить количество обрабатываемых строк (`--limit`). По умолчанию чтение начинается с 1-й строки, а значение `--limit` равно 100.
